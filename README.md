# Cookbook — Fall & Winter

44 Instant Pot and oven recipes for cold nights: soups, Italian sausage,
stews and bowls, curries, noodle soups, and roasted salads.

**Open it:** <https://teleokinetic.github.io/cookbook/>

## Put it on your phone

- **iPhone (Safari):** open the link → Share → **Add to Home Screen**.
- **Android (Chrome):** open the link → ⋮ → **Add to Home screen**.

It opens full screen like an app and works offline after the first visit.

## What's here

| File | What it is |
| --- | --- |
| `index.html`, `styles.css`, `app.js` | the app |
| `recipes.js` | every recipe — edit here to add or fix one |
| `sw.js` | offline cache (bump `CACHE` after changes so phones update) |
| `icons/` | the Happy Pot home-screen icon |
| `hearts-sync/` | optional Google Apps Script so both phones share hearts |
